# 禪宗跑江湖地圖

禪宗法脈的參學歷程、開悟因緣、住錫弘法之處與行腳路線，畫在真實的中國地圖上。
七十位祖師、四百餘個行腳節點、一百一十四則公案，五家以五色標示。

**內容已加密，需通行碼。**

| 頁面 | 內容 |
|---|---|
| `index.html` | 禪師圖傳 — 每位祖師一張自己的行腳路線圖，附生平與公案原文 |
| `map.html` | 全圖 — 縱軸時間 × 橫軸中國地圖 |
| `kids.html` | 兒童版 — 五段故事、二十二位祖師 |

行腳序列、籍貫、師承逐條校自 CBETA 原始 XML（《五燈會元》《景德傳燈錄》《指月錄》及各家語錄）。
年代多為推定，古地名的今地比定部分存疑，詳見頁內說明。
