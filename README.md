# 禪宗跑江湖地圖

禪宗法脈的參學歷程、開悟因緣、住錫弘法之處與行腳路線，畫在真實的中國地圖上。
七十位祖師、四百餘個行腳節點、一百一十四則公案，五家以五色標示。

## 「跑江湖」

這個詞本來出自禪門。唐代學人往來江西馬祖、湖南石頭兩家之間參學，故曰走江湖。
本圖所畫，正是那條路。

## 圖像

祖師像與寺院照片取自 [Wikimedia Commons](https://commons.wikimedia.org/)，僅採公有領域與創用 CC 授權者，作者與授權標示於頁尾「圖片出處」。

> **祖師像都不是寫真。**唐宋禪師無當代肖像存世，這些多半出自清代《佛祖正宗道影》一類的傳法圖像集，或日本禪林的頂相，是後人依想像與圖像慣例所繪，不能當作長相的根據。寺院照片是今日的建築，唐宋原構幾乎無存，多為後世重建。

行腳路線圖為本寺自製。

## 使用上的限度（請務必一併理解）

1. **年代多為推定。** 燈錄記事而不記年。凡標「約」者，是依生卒年、師承先後與停留年數推算，**並非原典明載**。
2. **生卒年採通說**（《五燈會元》《宋高僧傳》）。馬祖、百丈、趙州、黃檗、雲門、五祖法演諸家學界仍有異說。
3. **九處古地名的今地比定存疑**：潭州雲巖山、建陽佛迹嶺、益州大隋山、獨浮山、芙蓉山、石門、舒州四面山、新豐山、潭州雲蓋山。圖上以虛線外圈標示，座標僅表大致方位，**不可作地理考據之依據**。
4. **里程是各站之間大圓距離的總和**，用來呈現行腳規模，不是實際步行里程（唐宋陸路水路皆非直線，實際更遠）。
5. **公案原文的標點為編者所加**，CBETA 底本只有句號。
6. 長江、黃河為示意流路，非精確水系，未還原唐宋河道。
